# מוסך טופ גת – אתר

דף נחיתה למוסך טופ גת, אדר 8, אזור תעשיה קרית גת.
עברית (ברירת מחדל), ערבית ואנגלית. אפשר לפתוח שפה ישירות מהכתובת: `?lang=ar`, `?lang=en`.

## מבנה
- `index.html` – כל האתר (HTML, CSS ו-JS בקובץ אחד, הלוגו מוטמע בתוכו)
- `404.html` – דף "לא נמצא"
- `_headers` – הגדרות אבטחה ל-Netlify
- `robots.txt`
- `logo-*.webp`, `logo-640.jpg`, `favicon-48.png`, `apple-touch-icon.png` – לוגו ואייקונים

## פרסום ב-Netlify
Add new site → Import from Git → לבחור את המאגר הזה.
Build command: ריק · Publish directory: `/`
